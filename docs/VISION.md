## 一粒种子的自白

**武器就是武器。** 一把好刀，不需要知道握刀的人是谁，也不需要替握刀的人保管钥匙。它只需要有自己的说明书——重量、重心、刃角、保养方式——任何人拿起来都能用。

Tentacle 就是这把刀。它是一个独立的、可组合的、自带说明书的通用工具执行引擎。它不依赖任何特定 AI Agent 框架，不要求使用者理解 Helix 的 DAG 或 Mind 的知识图谱。它只做一件事：**接收标准化的调用请求，在安全的沙箱中执行工具，返回结构化结果，然后忘记一切。**

## 原子原则（10 条）

以下原则是 Tentacle 所有设计决策的最高依据。任何代码提交、架构决策、API 变更，若与本原则冲突，以本原则为准。

| # | 原则 | 一句话解释 | 对应规格 |
|---|---|---|---|
| 1 | **不预载，不应求则不动** | 启动只加载核心骨架；工具仅在执行请求到达时懒加载，用完即焚 | 白皮书 T1/T03 |
| 2 | **自带说明书，谁都能用** | 每个工具携带完整 Manifest（声明与执行体分离，SHA-256 绑定）；渐进披露 | 白皮书 T2/T02 |
| 3 | **多传输层，多协议共生** | 同一套工具经 HTTP/MCP/gRPC/STDIO 平等暴露，核心与传输解耦 | 白皮书 T3 |
| 4 | **零信任凭证：标签流转** | Tentacle 不存储不接触明文凭证；`identity_label` 流转，Tuck 边缘注入 | 白皮书 T5/T05（四修正 1） |
| 5 | **沙箱即契约，安全可验证** | 每个工具独立沙箱；完整性校验、权限声明、越权拒绝 | 白皮书 T5/T06 |
| 6 | **自适应觅食，信息饱和即止** | 信息增益评估 + 已见熵布隆过滤器，边缘价值递减即止，极致节能 | 白皮书 T6/T07（四修正 2） |
| 7 | **异步协程沙箱，ARM 可跑** | worker 池绑定物理核，QuickJS 协程级协作终止，不在端侧开 OS 线程 | 白皮书 T06（四修正 3） |
| 8 | **动态共识适配，独立可用** | Standalone 终端确认 / Helix CAP / MCP 回调；独立模式不返回 503 | 白皮书 6.7（四修正 4） |
| 9 | **身份与凭证分离** | 凭证由 Tuck 物理保管，Tentacle 只流转标签；宿主代签私钥永不在进程内 | 白皮书 T05/6.4 |
| 10 | **通用核心 + 生态适配** | Tentacle 面向全 AI Agent 社区；Helix 是其中一个用户（gRPC 适配） | 白皮书第四部分 |

## 生态位

Tentacle 是自包含的通用工具服务器。它不属于任何生态，但可以无缝融入任何生态。

| 调用方 | 使用方式 | 需要理解 Tentacle 内部？ |
|---|---|---|
| Helix（Anaphase） | gRPC 调用，说明书自动转 CAP 快照 | 否，仅需说明书 |
| Claude Desktop | MCP stdio 配置 | 否，MCP 客户端自动发现 |
| 任何 HTTP 客户端 | REST API + SSE 流式 | 否，看说明书即可 |
| 本地调试 | STDIO 模式 | 否，直接传 JSON |

**对齐链**：Tentacle 对齐 Anaphase（gRPC + 凭证标签 + 共识 Helix 模式）→ Anaphase 对齐 Mind（已完成 P10a-P11b）。
